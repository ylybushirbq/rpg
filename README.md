# 《烬火旅团》需求文档

本仓库当前只存放 **RPG 游戏需求规格**，尚未进入软件开发。

《烬火旅团》是一款以小队为核心的回合制角色扮演游戏。玩家组建旅团、培养角色、搭配装备与技能，在战斗中调度 **生命值（HP）**、**法力值（MP）** 与 **怒气值（Rage）** 三种资源。
