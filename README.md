## 1.0 做了什么简化

- 角色：只有玩家自己，没有队友、站位、羁绊
- 资源：只保留 HP、MP、RG
- 状态：没有眩晕、中毒等异常
- 职业：创建时选卫士或咒术师，没有转职
- 装备：武器 / 防具 / 饰品各一件，固定数值；去掉耐久、随机词缀、套装、强化
- 属性：升级加点保留；去掉派生属性软硬上限
- 战斗：1v1 回合制，必中、无暴击、无弱点击破
- 经验：角色有独立经验条；灰鼠 30、野狼 80、Boss 烬狼 200

2.0 的数据结构在 1.0 里留了空位（队友列表、词缀数组、状态数组），方便以后加，本阶段不实现。
