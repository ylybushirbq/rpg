# 《烬火旅团》

Godot 4.7 单机回合制 RPG。当前可玩的是 **1.0**：创建角色、据点养成、HD-2D 探索、暗雷遭遇、1v1 战斗。

游戏工程在 [`新建游戏项目/`](新建游戏项目/)。用 Godot 4.7 打开该目录后运行。
