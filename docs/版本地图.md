# 《烬火旅团》版本地图

| 项目 | 内容 |
| --- | --- |
| 文档版本 | 1.0.0 |
| 状态 | **设计分期已接受**（[DEC-VERSION-ROADMAP-001](../designos/01-decisions/DEC-VERSION-ROADMAP-001.md) OPT-001，2026-09-14） |
| 当前实现 | 仍是 **[1.0 最小可玩需求](./v1.0/最小可玩需求.md)**。1.1 及以后未开工 |
| 论证书 | [designos/08-exports/ember-brigade-version-roadmap.md](../designos/08-exports/ember-brigade-version-roadmap.md) |

小版本加厚当前核；大版本才换核。`docs/v2.0/需求规格说明书.md` 里的「第一期」已被本表拆开，**不要按那一节开工**。

```text
单人烬火   1.0 → 1.1 → 1.2 → 1.5
小队烬火   2.0 → 2.1 → 2.5
长线烬火   3.0 → 3.x / 上线后
```

| 版本 | 一句话目标 | 规格 | 代码 |
| --- | --- | --- | --- |
| **1.0** | 建角→据点→4 战→能赢能输，养成可读 | [最小可玩需求](./v1.0/最小可玩需求.md) | **现在** |
| **1.1** | 同样规则，外人能玩完 | [品质需求](./v1.1/品质需求.md) | 1.0 门通过后 |
| **1.2** | 金币有去处，路线更长，战斗公式不变 | [过渡需求](./v1.2/过渡需求.md) | 1.1 通过后 |
| **1.5** | 冷却、暴击、坚守/灼烧 | [过渡需求](./v1.5/过渡需求.md) | 1.2 通过后 |
| **2.0** | 旅团长 + 1 名队友，第二人必须改变决策 | [小队切片](./v2.0/小队切片.md) | **1.5 通过后** |
| **2.1** | 出战最多 4、前后排 | 愿景仍在 [2.0 全文](./v2.0/需求规格说明书.md) §4.4；实现前另写规格 | 2.0 切片通过后 |
| **2.5** | 技能装配、羁绊连携、最小状态集、阶段 Boss | 愿景在 2.0 全文 §7 / §4.6 / §9；实现前另写规格 | 2.1 通过后 |
| **3.0** | 多章节、转职、轻词缀、手柄、三档难度 | 对应原 2.0「第二期」+ 被推迟的量产项 | 2.5 通过后 |
| **3.x** | 打造、召唤、自动战斗、NG+ | 不得作为立项前提 | 3.0 之后 |

过门标准、失败标准和 Park/Cut 清单以论证书为准。1.0 内部验收后先跑 [EXP-LOOP-1.0-001](../designos/04-experiments/EXP-LOOP-1.0-001/)，再开 1.1。
