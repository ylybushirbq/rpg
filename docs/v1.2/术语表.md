# 《烬火旅团》术语表（1.2）

在 [1.0 术语表](../v1.0/术语表.md) 之上只补充本阶段新增或改义的词。战斗加厚见 [1.5 术语表](../v1.5/术语表.md)。

| 术语 | 代号 | 1.2 定义 |
| --- | --- | --- |
| 商店 | Shop | 据点固定货架，只卖药水和三件已有装备。无随机、无强化 |
| 事件节点 | Event | 不出战，二选一后回据点。每个存档只奖一次 |
| 余烬犬 | mob_ember_hound | 主线第 4 战新小怪 |
| 焦骨 | mob_cinder_bone | 打过余烬犬后可刷的精英，不挡通关 |
| 手动存档槽 | — | 3 个可由玩家写入的槽；据点自动槽仍然存在 |
| 冷却 | CD | 本版仍不使用，全部技能无冷却 |
| 暴击 | Crit | 本版不使用 |
| 状态 | statuses | 本版恒为空，不结算 |
