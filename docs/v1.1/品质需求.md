一句话：规则与 1.0 完全相同，但未参与开发的人能不靠作者讲解打完前两战。

1.1 只补阅读、反馈和空状态。不增加商店、暴击、冷却、状态、队友、新敌人公式。

能从 1.0 存档升上来：无新字段。坏档仍按 1.0 规则提示后回创建页。

## 1. 相对 1.0 变成什么样

```text
创建角色（沿用 1.0）
    → 据点（五入口不变）
    → 出征：仍是 4 战
    → 战斗里能看见伤害、RG、升级；可切 1x / 2x
    → 结算与失败规则沿用 1.0
```

通关 / 失败条件沿用 1.0。

---

## 2. 本版明确不做

相对 1.0 **零条新玩法**。尤其禁止：

- 商店、金币消耗
- 暴击、LUK 生效、冷却、`statuses` 结算
- 新节点、新敌人、新技能
- 队友、ATB、手柄必做、教学长流程、多语言
- 高精度立绘、法术全特效（占位图 + 占位音效即可）

---

## 3. 必须补上的品质

### 3.1 战斗可读

- 伤害结果必须能看见：飘字或战斗日志至少一种。内容含本次伤害数字。
- RG 变化必须能看见（获得与消耗）。
- 升级时必须能看见经验条走满 / 等级 +1（1.0 §5.1 已要求，本版当硬验收）。
- 失败结算必须写清：回据点、本场无经验无掉落、养成保留。

### 3.2 战斗倍速

- 提供 **1x / 2x** 动画或等待时间切换。
- 2x 下伤害、RG、胜负、经验结算与 1x **一致**。
- 不引入 ATB；仍是速度高的一方先手、每方一回合一个动作。

### 3.3 三条资源不只靠颜色

玩家 HP / MP / RG 必须同时有 **数字**（或 `当前/上限` 文字）。不能只靠红/蓝/橙条。敌人仍只显示名称 + HP 数字与条。

### 3.4 空状态与错误

1.0 §11 已写的空状态，本版必须能被未参与开发的人读懂，不允许空白或闪退：

- 背包空、技能未解锁、药水为 0
- 存档损坏：提示并从创建页开始
- 资源不足的技能按钮：禁用并写明缺 MP 或 RG

### 3.5 占位音效

至少四类占位音：选中按钮、命中、胜利、失败。无音源时可用引擎蜂鸣或静音开关，但不能让界面「点了完全没反应且无文字」。

## 4. 存档

沿用 1.0：一个自动槽，不保存战斗中途。1.1 不新增字段。

## 5. 验收（1.1 过关就行）

1.0 的 V1-01～V1-11 **必须仍然全过**。

| ID | 通过条件 |
| --- | --- |
| V11-01 | 战斗中能看见伤害数字（飘字或日志）；RG 涨落可见；升级时经验条按 1.0 播放 |
| V11-02 | 可在 1x / 2x 间切换；同一操作在两种速度下结算数字一致 |
| V11-03 | 未参与开发的人能不靠讲解创建角色并打完第 1 战；卡住时界面有原因而不是空白 |
| V11-04 | 玩家 HP/MP/RG 有数字，不只靠颜色 |
| V11-05 | 背包空、无药、技能未解锁、坏档都有一句话；点了没反应的按钮必须有禁用原因 |
| V11-06 | 全程没有商店、暴击、冷却、状态、队友、新节点入口 |

---

## 6. 给程序的约定

- 不要为日志另写一套伤害公式。日志只回放结算结果。
- 倍速只缩短表现等待，不跳过结算步骤。
- 1.0 数据表与存档结构保持兼容。
