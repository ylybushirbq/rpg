# 《烬火旅团》术语表（1.0）

只收录 **当前版本会用到的词**。2.0 名词见 [v2.0 术语表](../v2.0/术语表.md)。

| 术语 | 代号 | 1.0 定义 |
| --- | --- | --- |
| 旅团长 | — | 唯一可玩角色 |
| 职业 | class | 创建时二选一：卫士、咒术师。不能转职 |
| 生命值 | HP | 到 0 则战斗失败 |
| 法力值 | MP | 主动技能消耗 |
| 怒气值 | RG | 战斗内 0–100，满 100 可放怒技，战终清零 |
| 六维 | STR/AGI/INT/CON/SPI/LUK | 基础属性。LUK 本版可加点但不参与伤害 |
| 属性点 | — | 每级 3 点，手动加到六维 |
| 派生属性 | — | HP/MP 上限、物攻、法攻、防御、速度。无软硬上限 |
| 武器 / 防具 / 饰品 | — | 各 1 槽，固定数值，无词缀无耐久 |
| 怒技 | — | 消耗 100 RG 的技能 |
| 据点 | — | 休息、换装、加点、存档、出征 |
| 节点 | — | 路线上的一场战斗 |
