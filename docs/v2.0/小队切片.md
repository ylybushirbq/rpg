| 项目 | 内容 |

| 文档版本 | 2.0-slice.0 |
| 状态 | **1.5 完成之后才开工**。不是当前开发范围 |
| 对照 | 实现以本文为准，**不要**按 [需求规格说明书](./需求规格说明书.md) §2.4「第一期必须 4 人」开工。全文仍是愿景仓库。分期见 [版本地图](../版本地图.md) |

一句话：旅团长 + **1** 名可招募的异职队友。要证明第二人改变战斗决策，而不是把 HP 乘以 2。

---

## 1. 必须证明

假设 `ASM-PARTY-CHANGES-DECISIONS-001`：关掉队友会明显变难或变蠢，而不是只变慢。

体验路径：建角 → 招募 1 人 → 2v2 或 2v1 → 看见职业互补 → 回据点决定谁出战。

---

## 2. 包含

- 出战 2 人：必须含旅团长 + 1 队友
- 职业数据扩到 4 职；切片里队友职业必须与旅团长不同（卫士 / 咒术师 / 猎刃 / 祈火使）
- 仍 **速度高的先手**、攻击仍 **必中**（沿用 1.5 可保留暴击 / 两种状态 / 冷却）
- 装备仍是武器 / 防具 / 饰品各 1，固定数值
- 1 据点 + 很短路线，够打出双人差异即可
- 失败：全灭才失败；旅团长倒下战斗可继续（D7 倾向）
- 战斗 UI 两人各自的 HP/MP/RG 数字都要在

## 4. 通过 / 失败

| 通过 | 同一玩家能说出「这回合该谁行动 / 该打谁」；单人档对照同一路线，技能选择会变 |
| --- | --- |
| 失败 | 队友是第二个自动攻击按钮；两套资源条读不过来 |
| Go | 2.1 四人站位 |
| Pivot | 减 UI 或改队友 AI，仍不加词缀 / ATB |
| Stop | 小队核不成立则停留在 1.5 单人成品 |

数值、技能名、招募剧情在实现前另附表。本文只锁范围。
