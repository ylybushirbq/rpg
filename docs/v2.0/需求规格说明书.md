## 1. 文档目的

本文把「角色队友、战斗、装备、属性、技能、HP / MP / 怒气、升级加点、武器防具饰品」扩展为一份 **可评审、可验收、可指导后续设计** 的规格。

本文约定：

1. **第一期（V1）** 必须交付一个可玩闭环：建队、加点、换装、学技能、打完一场完整战斗并结算。
2. **第二期及以后** 仅作方向，不作为当前验收范围。
3. 未标注「第二期」的规则，默认属于第一期需求。
4. 公式给出的是 **设计意图与可调参数**，具体数值表在数值案确定；程序应按公式结构实现，数值走配置。

## 2. 产品概述

### 2.1 一句话

在余烬未熄的边境，玩家作为旅团长招募同伴，用属性加点、装备槽位和技能循环，把 HP、MP、怒气三条资源打成一场场可阅读、可逆转的回合战斗。

### 2.2 体验承诺（玩家应记住的三件事）

1. **小队比个人更强**：站位、职业互补、羁绊连携决定上限。
2. **三条资源都有代价**：HP 是存亡，MP 是稳定输出与控制，怒气是高风险爆发。
3. **养成能在战斗里读出来**：加点、装备、技能不是纸面数字，而会改变出手顺序、承伤能力和爆发窗口。

### 2.3 核心循环

```text
据点整备（编队 / 加点 / 换装 / 学技能）
        ↓
区域探索与遭遇
        ↓
回合战斗（HP、MP、怒气调度）
        ↓
结算（经验、掉落、羁绊）
        ↓
回到据点，形成更强编制
```

### 2.4 第一期玩法切片（必须完整）

- 1 名可自定义的旅团长
- 可招募的队友至少 4 名（名册 5 人，出战 4 人，含旅团长）
- 职业 4 个（见 4.3）
- 1 个据点 + 1 条探索路线 + 至少 8 场不同遭遇（含 1 个 Boss）
- 完整属性、技能、装备、战斗、结算
- 失败可重试，不删档

### 2.5 明确不做（第一期）

- 联机、PVP、交易行、内购
- 开放大世界、坐骑、住房
- 装备耐久损耗、打造生产流水线
- 实时动作、自动战斗托管
- 复杂恋爱线、多周目 New Game+
- 语音演出与过场动画长片（可用立绘 + 文本）

## 3. 用户与使用场景

### 3.1 目标玩家

- 喜欢《最终幻想》《歧路旅人》《石中诗》一类 **可读规则的小队 RPG** 的玩家
- 愿意花时间在编队、站位、技能轴上做选择，而不是无脑平砍
- 单局战斗 3–8 分钟，整备 2–5 分钟

### 3.2 关键场景

| ID | 场景 | 成功标准 |
| --- | --- | --- |
| S1 | 新玩家创建旅团长并打完教学战 | 10 分钟内理解 HP / MP / 怒气与普攻、技能、防御 |
| S2 | 招募第 2 名队友并调整站位 | 能看出前排承伤、后排更安全 |
| S3 | 升级后加点并感到角色变了 | 同一敌人的战斗时长或伤害结构可感知变化 |
| S4 | 换武器 / 防具 / 饰品 | 面板与战斗表现同步变化，职业限制生效 |
| S5 | 学会怒技并在战斗中放一次 | 怒气来源、消耗、释放条件都清楚 |
| S6 | 两人羁绊解锁连携技 | 满足条件时可释放，不满足时有明确提示 |
| S7 | 全灭后重试 | 保留养成进度，可改编队再战 |
| S8 | Boss 战资源管理 | 需要存怒气、控 MP、处理机制，而不是纯堆数值 |

## 4. 角色与队友系统

### 4.1 角色实体

每个角色是独立养成单位，包含：

- 身份：角色 ID、名称、是否旅团长、立绘 / 模型 ID、定位标签
- 职业与等级
- 六维属性、属性点库存、技能点库存
- HP / MP 当前值与上限；怒气当前值与上限（怒气战斗外为 0）
- 技能列表（已学、等级、装备中的主动栏）
- 装备槽（武器 1、防具 3、饰品 2）
- 站位偏好（可被玩家覆盖）
- 羁绊表（与其他角色的分数与等级）
- 战斗外状态：受伤、中毒残留等（第一期仅保留「据点外 HP/MP 不清满」可选规则，默认据点休息回满）

### 4.2 旅团长规则

- 玩家必须拥有且只能拥有 1 名旅团长。
- 旅团长不可解雇、不可移出名册，可不编入「探索跟随」之外的闲置展示，但 **出战小队必须包含旅团长**。
- 创建时可设置：名称、性别呈现、脸型 / 发色（有限预设）、初始职业。
- 旅团长死亡（战斗不能）**不等于** 立刻失败；小队仍可继续。全员战斗不能才失败。
- 旅团长拥有「指挥」被动：每场战斗开始时，出战小队全体怒气 +5% 上限（可配置）。

### 4.3 职业（第一期 4 职）

| 职业 | 定位 | 主属性 | 武器许可 | 资源侧重 |
| --- | --- | --- | --- | --- |
| 卫士 | 前排坦克 / 反击 | 体质、力量 | 剑、斧、盾（盾占武器形态，见装备） | HP 与怒气，MP 低 |
| 猎刃 | 爆发输出 / 弱点 | 敏捷、幸运 | 双刃、弓 | 怒气爆发，MP 中 |
| 咒术师 | 法术输出 / 控场 | 智力、精神 | 法杖、魔导书 | MP 核心，怒气转大招 |
| 祈火使 | 治疗 / 增益 / 解控 | 精神、智力 | 法杖、圣印 | MP 核心，怒气用于群体应急 |

第二期可扩展：刺客、召唤、枪械、吟游等。第一期每个职业至少 1 名可玩角色（旅团长可选四职，固定队友覆盖其余职业）。

职业限制：

- 装备武器类型不匹配则不可装备。
- 技能树按职业解锁；转职后原职业主动技卸下，被动按 50% 效果保留或全部失效（**建议第一期：转职关闭**，见待决策清单）。

### 4.4 名册、出战与站位

| 项目 | 规则 |
| --- | --- |
| 名册上限 | 第一期 8 人 |
| 出战人数 | 1–4 人，必须含旅团长 |
| 站位格 | 2 前排 + 2 后排 |
| 空位 | 允许 3 人出战（例如 2 前 1 后） |
| 全前排 / 全后排 | 允许，但给予明确风险提示 |

站位效果（可配置系数，下列为设计默认）：

| 位置 | 受到近战伤害 | 受到远程 / 法术伤害 | 近战技能命中修正 | 治疗 / 辅助效率 | 被点名概率 |
| --- | --- | --- | --- | --- | --- |
| 前排 | 100% | 100% | +10% | 100% | 高 |
| 后排 | 70% | 110% | -20%（近战武器） | 115% | 低 |

- 后排角色使用近战武器普通攻击时，伤害额外 -15%。
- 若前排全部战斗不能，后排视为被拉到前排（承伤系数按前排），直到有人被复活且玩家在回合内选择「重整阵型」。

### 4.5 招募、离队与替换

- 招募：剧情或据点对话触发，确认后进入名册，自带初始等级、装备、技能。
- 离队：第一期仅剧情强制离队；玩家不可随意解雇（避免把养成做成抛弃）。
- 战斗中不可换人。战斗外在据点或安全篝火可更换出战小队与站位。
- 未出战角色仍获得 **50% 战斗经验**（可配置），避免养成惩罚过重。

### 4.6 羁绊

- 任意两名出战过的角色之间累积羁绊值。
- 来源：共同出战结算、使用连携技、据点互动（第一期每名队友 1 段短对话即可）。
- 等级：疏远 0 / 相识 1 / 信任 2 / 生死 3。
- 效果：
  - 1 级：相邻站位时受疗 +5%
  - 2 级：解锁该配对的连携技
  - 3 级：连携技强化，且一方战斗不能时另一方怒气获得 +10%

### 4.7 角色界面需求

必须能在不进入战斗的情况下看清：

- 当前 HP / MP / 怒气上限
- 六维与派生属性（含装备前后对比）
- 装备槽与已穿戴预览
- 已学技能、装配中的主动技能
- 与其他角色的羁绊等级
- 职业标签与可装备类型

空状态：名册未满时显示可招募提示，不显示假角色。

## 5. 属性系统

### 5.1 基础六维

| 属性 | 简称 | 主要影响 |
| --- | --- | --- |
| 力量 | STR | 物理攻击、部分怒技倍率、负重（若启用） |
| 敏捷 | AGI | 速度、物理暴击率、闪避、近战命中 |
| 智力 | INT | 法术攻击、部分技能命中、MP 回复效率 |
| 体质 | CON | HP 上限、物理防御、怒气上限、抗暴 |
| 精神 | SPI | MP 上限、法术防御、治疗量、异常抗性 |
| 幸运 | LUK | 暴击伤害、掉落修正、异常命中、少量闪避 |

创建角色时按职业给出 **初始六维模板**，玩家在创建旅团长时可获得 5 点自由分配（每维最多 +3）。

### 5.2 升级与加点

| 项目 | 规则 |
| --- | --- |
| 等级上限 | 第一期 20 级 |
| 升级获得属性点 | 每级 3 点 |
| 升级获得技能点 | 每级 1 点；5 / 10 / 15 / 20 级额外 +1 |
| 单次分配 | 可一次把库存点完，也可留着 |
| 单维投入上限 | 等级 + 10（硬上限）；超过职业推荐值后收益递减（软上限） |
| 洗点 | 据点 NPC 提供，消耗稀有道具「余烬露」。第一期送 2 个 |

加点即时生效。未加点的属性点必须在角色面板明显提示，避免玩家漏点。

升级时 **固定成长**：每级自动增加少量 HP / MP（职业表），与加点无关，保证即使乱点也能变强。

### 5.3 派生属性

下列由公式计算，界面要显示最终值，并可展开「来源构成」（等级 / 六维 / 装备 / 技能 / 临时）。

| 派生 | 设计公式（默认） |
| --- | --- |
| HP 上限 | `职业基础HP(等级) + CON × 8 + 装备HP + 技能HP` |
| MP 上限 | `职业基础MP(等级) + SPI × 5 + INT × 1 + 装备MP` |
| 怒气上限 | `50 + CON × 0.5 + 装备怒气 + 技能`，四舍五入，下限 50，上限 150 |
| 物理攻击 | `力量系数 + 武器攻击 + 技能` |
| 法术攻击 | `智力系数 + 武器法攻 + 技能` |
| 物理防御 | `体质系数 + 防具防御 + 技能` |
| 法术防御 | `精神系数 + 防具魔抗 + 技能` |
| 速度 | `职业基础速度 + AGI × 1.2 + 装备速度 - 重甲惩罚` |
| 命中 | `90% + AGI × 0.15% + LUK × 0.05% + 武器命中`，上限 99% |
| 闪避 | `5% + AGI × 0.1% + LUK × 0.05%`，上限 40% |
| 暴击率 | `5% + AGI × 0.12% + LUK × 0.2%`，上限 50% |
| 暴击伤害 | `150% + LUK × 0.5%`，上限 250% |
| 治疗加成 | `SPI × 0.4% + 装备` |
| 怒气获取 | `100% + 被动 + 饰品` |

显示规则：百分比类显示到小数点后 1 位；整数类向下取整显示，计算用浮点中间值。

### 5.4 软上限示例

以力量为例：当 `STR > 等级 × 2 + 职业修正` 时，超出部分对物理攻击的转化率从 100% 降为 50%。其他维同样处理。界面在该属性旁显示「收益递减」。

### 5.5 面板对比

更换装备、预览加点时，必须提供 **前后对比**：变红下降、变绿上升。怒气上限变化也要对比。

## 6. 人物资源：HP、MP、怒气

三条资源必须同时存在于角色头像条上，战斗内始终可见。

### 6.1 生命值 HP

- 范围：0 到 HP 上限。
- 伤害先扣护盾（若有），再扣 HP。
- HP ≤ 0：进入战斗不能。溢出伤害不结转到复活后。
- 战斗不能：无法行动、无法被选为大部分敌方「随机攻击」以外的辅助目标；仍占站位。
- 复活：HP 回复到技能指定比例（默认 20%），清除部分控制，怒气不变或按技能说明。
- 战斗外：离开据点探索时，默认 **保持战斗结束时的 HP**；进入据点休息或使用营地回复。允许「安全区自动回满」作为选项，默认开。

死亡惩罚：第一期无永久死亡。

### 6.2 法力值 MP

- 范围：0 到 MP 上限。
- 技能标红且不可点选当 MP 不足（显示缺口）。
- 普通攻击、防御、移动重整不耗 MP。
- 回复来源：技能、道具、防御（少量）、装备每回合回复、战斗结束回复 10% 上限（可配置）。
- 禁止出现「MP 为负」。

### 6.3 怒气值 Rage

怒气是本游戏战斗节奏的核心差异点。

#### 6.3.1 基本规则

- 仅在战斗中存在。进入战斗为 0（偷袭方 +10，被偷袭 - 保持 0；旅团指挥被动再加）。
- 范围：0 到怒气上限。
- **战斗胜利 / 失败 / 逃跑后清零**，不带到下一场。
- 战斗不能时怒气冻结，不自然衰减；复活后保留。

#### 6.3.2 获取

| 事件 | 默认获得 |
| --- | --- |
| 造成普通攻击伤害 | +8 |
| 受到 HP 伤害 | `+ 伤害/上限HP × 40`，单次上限 +20 |
| 暴击 | 额外 +5 |
| 击杀 | +12 |
| 防御 | +10 |
| 友方战斗不能（自身未 KO） | +15 |
| 弱点击破 | +10 |
| 使用消耗 MP 的技能 | 默认不加，除非技能写明 |

获取受「怒气获取」乘区影响，再四舍五入。

#### 6.3.3 消耗与阈值

- 怒技通常消耗 30 / 50 / 100（小 / 中 / 大）。
- 部分职业有「怒气阈值被动」：例如卫士 ≥50 时受伤 -10%，但被治疗 -10%（高怒代价）。
- 咒术师「过载」：怒气 ≥80 时下一发法术倍率提升，但该法术额外消耗 10% 当前 HP（可被护盾吸收）。

#### 6.3.4 衰减与过热（可选开关，建议第一期开启轻度版）

- 若连续 2 个自身回合怒气 ≥90 且未释放怒技：每回合结束 -10 怒气，并进入「躁动」1 回合（受到伤害 +10%）。
- 目的：避免只攒不满放，也不强迫每场必放大招。

#### 6.3.5 界面

- HP 红、MP 蓝、怒气橙。三条分离，不可合并成一条。
- 怒气达到可释放的最低怒技阈值时，头像闪烁或技能按钮高亮。
- 鼠标 / 焦点到怒气条时显示：当前值 / 上限、下一阈值、本回合预计变化。

## 7. 技能系统

### 7.1 技能分类

| 类型 | 说明 |
| --- | --- |
| 主动技能 | 战斗中占用行动，消耗 MP 和 / 或怒气 |
| 怒技 | 主动技子类，必须消耗怒气，可另耗 MP |
| 被动技能 | 始终生效或在条件满足时生效，不占行动 |
| 连携技 | 双人主动，消耗双方资源，占释放者行动，协作者本回合若尚未行动则「协力标记」（不剥夺其行动，但该回合速度 -10%） |
| 战场技 | 旅团长限定，改变站位、指挥集火，消耗指挥次数（每场 1–2 次） |

### 7.2 技能装配

- 每个角色 **主动栏 4 格**（不含普通攻击、防御、道具、重整）。
- 已学技能可超过 4 个，战斗外装配。
- 怒技也占主动栏。至少保证每个职业有 1 个怒技可装配。
- 被动不占栏，但有「生效被动上限 6 个」；超出需在面板勾选（第一期技能总量不大，可全部生效）。

### 7.3 学习与升级

- 技能树按职业分三系（例如卫士：守护 / 反击 / 怒焰）。
- 前置：直线或浅分支，禁止深锁死。
- 学习消耗技能点；升级同一技能再耗点。
- 技能等级 1–3。升到 3 改变描述（缩短 CD、加效果，而非纯加数字）。
- 等级不够不可学（技能有等级门槛）。

### 7.4 技能描述必须包含的字段

每条技能在数据与 UI 上需要：

- 名称、图标、类型、目标类型（单体敌 / 群体敌 / 单体我 / 全体我 / 自身 / 死亡队友）
- 消耗：MP、怒气、HP（若有）
- 冷却：自身回合数
- 伤害或治疗公式引用（物理 / 法术 / 真实 / 治疗）
- 附加状态、命中类型（必中 / 常规 / 异常检定）
- 站位要求（例如「仅前排」）
- 释放失败条件文案

### 7.5 冷却与行动

- 公共行动：每回合每名角色只能选 1 个主动行动。
- 技能 CD 以「该角色自身回合」计。
- 被控制跳过回合时，CD 仍减少 1（避免晕控永久锁技能）。第一期采用此规则。

### 7.6 职业技能示例（规格级，非最终数值）

**卫士**

- 主动：盾击（MP 低，短晕或减怒气敌人）
- 主动：援护（指定队友，本回合转嫁 50% 伤害）
- 怒技：铁壁（消耗 50 怒气，获得高额减伤护盾）
- 被动：受击积攒怒气 +20%

**猎刃**

- 主动：割裂（上出血）
- 主动：瞄准弱点（下一次攻击必吃弱点修正）
- 怒技：处刑（消耗 100，对 HP 低于 30% 目标真实伤害提高）
- 被动：暴击获得额外怒气

**咒术师**

- 主动：元素弹、范围术、沉默
- 怒技：湮灭术（高 MP + 50 怒气）
- 被动：用技能击杀回复 10% MP

**祈火使**

- 主动：单疗、群疗、驱散
- 怒技：逆焰苏生（消耗 100，复活并给短无敌）
- 被动：治疗后自身获得少量怒气

### 7.7 连携技

- 条件：羁绊 ≥2、双方均未战斗不能、至少一方已行动或可立即行动（设计为：当前行动者发起，目标队友必须在场）。
- 每场每对角色限 1 次（可配置）。
- 消耗：发起者 MP + 双方各 20 怒气。
- 若资源不足，按钮禁用并写明缺谁的什么资源。

### 7.8 技能冲突

- 同类增益默认取高不叠加（防御提升 A 与 B 取最大值）。
- 不同类增益可叠加（防御提升 + 护盾）。
- 减益同类叠层有上限（出血最多 3 层）。

## 8. 装备系统

### 8.1 槽位

| 槽位 | 数量 | 说明 |
| --- | --- | --- |
| 武器 | 1 | 决定普攻类型与武器技能许可 |
| 头部防具 | 1 | 偏 MP、精神、抗性 |
| 躯干防具 | 1 | 偏 HP、双防 |
| 足部防具 | 1 | 偏速度、闪避、抗控制 |
| 饰品 | 2 | 两槽对等，不可装两件「唯一」同名 |

第一期不设副手独立槽。若武器为「剑盾」，盾的防御并入该武器数据。弓、法杖、魔导书无格挡。

### 8.2 武器类型

| 类型 | 普攻形态 | 典型职业 |
| --- | --- | --- |
| 剑盾 | 近战单体，可格挡 | 卫士 |
| 斧 | 近战单体，高伤低速 | 卫士 |
| 双刃 | 近战单体，高暴击 | 猎刃 |
| 弓 | 后排远程，可打后排无惩罚 | 猎刃 |
| 法杖 | 法术普攻 | 咒术师、祈火使 |
| 魔导书 | 法术普攻，附加 MP | 咒术师 |
| 圣印 | 弱普攻，治疗加成 | 祈火使 |

职业武器白名单见 4.3。白名单外无法装备。

### 8.3 防具重量

| 重量 | 速度 | 怒气获取 | 适合 |
| --- | --- | --- | --- |
| 轻 | +速度 | 正常 | 猎刃、咒术 |
| 中 | 无修正 | 正常 | 祈火使、通用 |
| 重 | -速度 | +10% | 卫士 |

混穿按三件重量取众数；平票则按躯干。

### 8.4 饰品

饰品是差异化来源，效果应「有一句人话」：

- 开场怒气 +15
- 治疗时 20% 加护盾
- 击杀回复 8% MP
- 免疫第一次致死（每场一次）
- 对燃烧敌人伤害提高

禁止无描述的纯隐藏数值堆砌。每件饰品主效果 ≤2 条。

### 8.5 稀有度与词缀

| 稀有度 | 颜色 | 词缀数 | 备注 |
| --- | --- | --- | --- |
| 普通 | 白 | 0–1 | 商店、前期掉落 |
| 精良 | 绿 | 1–2 | 常用 |
| 稀有 | 蓝 | 2–3 | 有可能带套装名 |
| 史诗 | 紫 | 3 + 特效 | Boss / 宝箱 |
| 传说 | 橙 | 固定特效 | 第一期最多 2–3 件，剧情或隐藏 Boss |

词缀池：六维、HP、MP、怒气上限、攻防、速度、暴击、抗性、技能伤害、怒气获取。

同一装备不能出现互斥词缀（如同时「受疗提高」与「受疗降低」）。

### 8.6 套装

第一期 2 套示例即可：

- 守火甲 2 件：受击怒气 +10%；4 件：铁壁类技能 CD -1
- 旅团徽记（饰品不参与）：武器 + 躯干 2 件：连携技伤害 +15%

### 8.7 获取、穿戴、替换、出售

- 来源：战斗掉落、宝箱、据点商店、剧情赠与。
- 穿戴即时改面板；战斗中不可换装。
- 替换时弹出对比。
- 背包上限 80 格。满时掉落进临时邮箱 / 战场拾取列表，回据点必须清理才能再探索。
- 可出售普通 / 精良；史诗以上需二次确认。
- 绑定：剧情传说绑定角色或账号；其余可自由给名册内任何人（受职业限制）。

### 8.8 强化（第一期轻量）

- 仅武器与躯干可强化 +1 ~ +3，消耗金币与强化石。
- 失败不损坏（第一期 100% 成功）。
- +值只加主属性（武器攻击或躯干双防），不加词缀。

附魔、重铸、镶孔放到第二期。

## 9. 战斗系统

### 9.1 战斗定位

**速度条回合制**：全场单位按速度填充行动条，谁先满谁行动。不是纯 ATB 实时（暂停选指令），玩家选指令时时间停止。

### 9.2 进入战斗

1. 遇敌或剧情触发。
2. 先攻判定：`队伍平均速度 + 幸运修正 + 场地 + 是否主动接触`。
3. 结果：先攻 / 普通 / 被偷袭。
4. 生成敌方阵容、场地元素、波次（第一期以单波为主，Boss 可多阶段）。

### 9.3 单次回合流程

```text
行动条满 → 开始该单位回合
  → 回合开始触发（DOT、再生、状态计时）
  → 若被控制且无法行动：跳过选择，进入结束
  → 玩家/AI 选择行动与目标
  → 合法性校验（资源、CD、站位、目标存活）
  → 结算命中、暴击、伤害、状态、怒气
  → 击破、击杀、连携询问（若条件满足可插在技能后）
  → 回合结束触发
  → 检查胜负
```

玩家在选目标阶段可取消回技能选择。不可在动画结算中取消。

### 9.4 基础行动

| 行动 | 消耗 | 效果 |
| --- | --- | --- |
| 普通攻击 | 无 | 武器伤害，加怒气 |
| 技能 | 按技能 | 见技能系统 |
| 道具 | 1 个消耗品 | 药品、解控、怒气瓶（怒气瓶每场每角色限 1） |
| 防御 | 无 | 本回合受到伤害 ×0.5，怒气 +10，速度条下次填充 +10% |
| 重整阵型 | 无 | 交换两名我方站位，本回合不造成伤害 |
| 逃跑 | 无 | 非 Boss 可逃；成功率看速度差。失败则该角色回合浪费 |

### 9.5 目标与范围

- 默认点名单体。
- 群体技能按「全体敌 / 全体我 / 一排」。
- 隐身、无敌、不可选中要在目标列表里置灰并写原因。
- 治疗不可选定敌方；攻击不可选定我方（除非技能是「可对友军释放的牺牲技」）。

### 9.6 命中、暴击、伤害

**命中**：`命中 - 闪避`，夹在 5%–99%。控制类另做异常命中：`基础率 + 精神差`。

**伤害主公式（设计用）**：

```text
基础 = 技能倍率 × 攻击项 + 技能固定值
防御修正 = 100 / (100 + 有效防御)
随机 = 0.95 ~ 1.05
位置修正、弱点修正、暴击修正、护盾、减伤、易伤
最终伤害 = max(1, 向下取整后的结果)
```

治疗公式类似，但用治疗加成，暴击可允许（祈火使被动解锁）。

真实伤害：忽略防御，不忽略减伤护盾（需在技能上标明）。

### 9.7 弱点与击破

- 敌人有 1–2 个弱点标签（火 / 冰 / 雷 / 斩 / 刺 / 打）。
- 打中弱点：伤害 ×1.35，目标行动条回退 10%，攻击者怒气 +10。
- 击破槽：隐藏或显示均可，第一期 **显示**。击破后 1 回合易伤 ×1.25 且速度下降。
- 玩家角色也可有抗性，但第一期玩家弱点只通过装备抗性体现，不强制玩家击破。

### 9.8 状态效果（第一期最小集）

**减益**：出血（DOT）、燃烧（DOT+火弱）、中毒、减速、命中下降、沉默（禁技能）、眩晕（禁行动 1 回合）、嘲讽。

**增益**：攻击提升、防御提升、加速、护盾、再生、反伤、隐匿（提高闪避）。

规则：

- 大多数持续 2–3 回合。
- Boss 对硬控有抗性：连续眩晕递减。
- 同一目标眩晕不可被同技能刷新超过上限。
- 驱散分「减益驱散」与「增益驱散」。

### 9.9 胜负

- 胜利：全部敌人战斗不能（或多波全清）。
- 失败：我方出战全员战斗不能。
- 逃跑成功：无经验或少量安慰经验，不掉装备，消耗的道具不退回。
- 失败：保留消耗的道具（第一期不惩罚道具，避免挫败）；经验不给。可立即重试本场遭遇。

### 9.10 敌人 AI（需求级）

- 普通怪：加权随机（打前排、补刀、放技能）。
- 精英：有简单循环（蓄力 → 强击）。
- Boss：阶段表 + 可被玩家打断的蓄力；必须使用 HP / MP / 怒气中至少两种机制（例如 Boss 怒气满放灭团技，玩家可用卫士嘲讽或猎刃处刑窗口）。

禁止第一期出现无法读招的即死。即死技必须有蓄力回合或可驱散标记。

### 9.11 战斗 UI 必备

- 我方 4 人：头像、HP、MP、怒气、状态图标、行动条
- 敌方：名称、HP 条（Boss 显示阶段）、状态、弱点图标
- 当前行动者高亮
- 技能栏显示消耗与不可用原因
- 战斗日志（可折叠）：伤害、暴击、未命中、状态
- 暂停 / 设置（速度 1x/2x 动画，第一期要有）

空、加载、错误：

- 进入战斗资源加载失败：可返回据点，不扣道具。
- 无可用目标：禁用确认键。
- 全员被控：自动跳过并提示「无法行动」。

## 10. 成长、经济与探索（支撑系统）

没有这些，五大系统无法闭环。第一期保持最小。

### 10.1 经验与等级

- 经验按敌人等级差衰减，避免碾压刷。
- 角色单独升级，不设账号等级。
- 升级可发生在战斗结算时，弹出加点提醒。

### 10.2 货币

- 金币：商店、强化、洗点以外的服务。
- 无第二货币充值。
- 掉落金币与装备分开展示。

### 10.3 据点功能

- 休息（回满 HP / MP，怒气本来就是 0）
- 编队与站位
- 装备与强化
- 技能与加点
- 商店
- 队友对话（羁绊）
- 出征（进入路线）

### 10.4 探索路线

线性节点图即可：战斗节点、事件节点、篝火、宝箱、Boss。

事件节点示例：二选一补给、强制遭遇、获得饰品。

不需要无缝地图。

### 10.5 难度

- 故事、标准、严苛三档，影响敌人 HP / 伤害 / 击破抗性，不影响掉落种类（可影响数量）。
- 可随时在据点改难度。

### 11.1 信息架构

### 11.3 文案

- 技能、装备、状态必须中文完整描述，禁止「ATK UP」这类无解释缩写作为唯一说明。
- 数字与规则一致，描述与公式不符视为缺陷。

### 11.4 适配

- 桌面 16:9 为第一目标。
- 战斗中底部指令 + 顶部状态，避免遮挡弱点图标。
- 字体与条的对比度可在战斗快速阅读。

## 12. 系统规则边界与数据原则

### 12.1 配置化

职业、技能、装备、敌人、关卡、对话应用数据表驱动，而不是写死在逻辑里。需求阶段即要求后续实现遵守这一点。

### 12.2 随机

- 战斗伤害浮动、掉落、词缀需要种子，保证同一场重进可复现（便于测试）。
- 玩家可见的概率必须真实：显示 20% 就是 20%。

### 12.3 存档

- 据点自动存档。
- 战斗中退出：视为逃跑失败或回到战前节点（第一期建议 **战前回滚**，不保存战中）。
- 至少 3 个手动槽。
- 版本变更时旧档能读或明确不兼容提示。

### 12.4 作弊与调试（开发用，不进玩家包）

后续开发需要：无敌、满资源、跳关、给装备。需求文档预先承认其存在，避免测试阻塞。
