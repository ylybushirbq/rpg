# 《烬火旅团》术语表

本文与 [需求规格说明书](./需求规格说明书.md) 配套，统一产品、策划、程序、测试使用的名词。

## 角色与编制

| 术语 | 英文/代号 | 定义 |
| --- | --- | --- |
| 旅团长 | Leader | 玩家主控角色，不可离队，可改名与外貌，职业可在规则内转职 |
| 队友 | Companion | 可招募、培养、编入出战小队的非主控角色 |
| 名册 | Roster | 已招募的全部角色列表，包含出战与待命 |
| 出战小队 | Party | 当前可进入战斗的最多 4 人编制 |
| 前排 / 后排 | Front / Back | 小队站位。前排承伤更高、近战命中更好；后排更安全、远程与辅助更有效 |
| 羁绊 | Bond | 两名角色之间的关系等级，影响连携技解锁与部分战斗加成 |
| 职业 | Class | 决定可装备武器类型、技能树、主属性倾向 |
| 转职 | Job Change | 达到条件后切换职业分支，保留等级，按规则重置或继承部分技能 |

## 资源与状态

| 术语 | 英文/代号 | 定义 |
| --- | --- | --- |
| 生命值 | HP | 归零则该角色战斗不能（无法行动）。小队全员战斗不能则战斗失败 |
| 法力值 | MP | 施放多数主动技能消耗的资源，战斗外可通过休息、道具回复 |
| 怒气值 | Rage / RG | 战斗中积攒的爆发资源，用于怒技与部分职业机制。默认战斗结束清零 |
| 战斗不能 | KO | HP ≤ 0 的状态。不可行动，部分复活技可解除 |
| 异常状态 | Status Effect | 增益（Buff）或减益（Debuff），有持续回合、叠层、互斥与驱散规则 |
| 控制 | Crowd Control | 眩晕、沉默、冻结等限制行动或技能的减益 |

## 属性与成长

| 术语 | 英文/代号 | 定义 |
| --- | --- | --- |
| 基础六维 | Primary Stats | 力量、敏捷、智力、体质、精神、幸运 |
| 派生属性 | Derived Stats | 由六维、等级、装备、技能计算得出的攻防、速度、暴击等 |
| 属性点 | Stat Point | 升级获得，可自由分配到六维 |
| 技能点 | Skill Point | 升级或任务奖励，用于点亮或升级技能 |
| 经验值 | EXP | 击败敌人、完成目标获得，用于角色升级 |
| 软上限 | Soft Cap | 超过后收益递减的属性阈值 |
| 硬上限 | Hard Cap | 不可再提升的绝对上限 |

## 战斗

| 术语 | 英文/代号 | 定义 |
| --- | --- | --- |
| 行动值 | ATB / Speed Gauge | 由速度驱动的回合条，满值即可选择行动 |
| 普通攻击 | Basic Attack | 不消耗 MP，少量积攒怒气 |
| 怒技 | Rage Skill | 消耗怒气的高威力或改变战局的技能，通常有释放条件 |
| 连携技 | Combo Skill | 满足羁绊与站位条件时，两名角色共同释放的技能 |
| 防御 | Guard | 本回合减伤并加速怒气回复，但放弃进攻 |
| 弱点 | Weakness | 元素或武器类型克制，造成更高伤害并额外积攒行动惩罚 |
| 击破 | Break | 弱点连续命中后进入的易伤窗口 |
| 先攻 / 被偷袭 | Ambush | 遇敌判定结果，影响开场行动条与第一回合怒气 |

## 装备与物品

| 术语 | 英文/代号 | 定义 |
| --- | --- | --- |
| 武器 | Weapon | 主手装备，决定普通攻击形态与部分技能可用性 |
| 防具 | Armor | 头部、躯干、足部三槽，提供防御与生命相关加成 |
| 饰品 | Accessory | 两槽，提供特殊效果、抗性或稀有属性 |
| 词缀 | Affix | 装备上的随机或固定附加属性 |
| 套装 | Set | 穿戴同系列多件后激活的额外效果 |
| 耐久 | Durability | 可选模块。第一期默认关闭，装备不损耗 |
| 消耗品 | Consumable | 战斗内外可使用的回复、解控、怒气药剂等 |

## 流程与界面

| 术语 | 英文/代号 | 定义 |
| --- | --- | --- |
| 世界地图 | World Map | 区域选择与据点入口 |
| 据点 | Hub | 可补给、换装、编队、对话、接任务的安全区 |
| 遭遇 | Encounter | 一次战斗实例，含敌人波次、场地、先攻判定 |
| 结算 | Result | 战斗结束后的经验、掉落、羁绊变化展示 |
| 第一期 | V1 | 需求规格中承诺实现的最小完整玩法切片 |
