# 《烬火旅团》术语表（1.5）

在 [1.2 术语表](../v1.2/术语表.md) 之上只补充本阶段新增或改义的词。2.0 名词见 [v2.0 术语表](../v2.0/术语表.md)。

商店、事件、余烬犬、焦骨、手动存档槽的定义以 1.2 为准，本表不重复。

| 术语 | 代号 | 1.5 定义 |
| --- | --- | --- |
| 冷却 | CD | 以自身回合计。只加在贵技能上 |
| 坚守 | guard_stance | 1 回合减伤 50%，不叠层 |
| 灼烧 | burn | 目标回合开始扣 6 HP，持续 2 回合，不叠层 |
| 暴击 | Crit | `min(25, 5+LUK)%` 概率使本次攻击伤害 ×1.5。仍必中 |
| 状态 | statuses | 本版只允许坚守与灼烧。没有控制、护盾、驱散 |
| LUK | — | 本版起影响暴击 |
