## Creative Thesis

这款游戏通过玩法要证明的不是「余烬世界观」，而是：

**玩家用三条有代价的资源（HP / MP / RG）打可读、可逆转的回合；养成变化必须能在下一场战斗里看出来。**

1.x 用一个人证明这件事。2.x 再问第二个人是否让决策变强，而不是把血条加倍。3.0 才用章节、职业分支和装备深度把「旅团」做成可发布体量。

它拒绝变成：无脑平砍数值页、实时动作、联机交易行、或「系统清单齐全但核心循环没人重复」的伪 JRPG。

## Player Verbs and Core Loop

### 玩家动词

| verb | 1.0 频率 | 为什么重要 | 何时升级 |
| --- | --- | --- | --- |
| 选行动（攻 / 技 / 防 / 药） | high | 80% 时间 | 1.5 加冷却与状态 |
| 看三条资源再决定 | high | 本作差异点 | 1.0 就必须成立 |
| 加点 / 换装 | medium | 养成可读 | 1.0 起；2.x 才变编制 |
| 选节点出征 | medium | 循环闭环 | 1.2 变长；2.0 才变探索 |
| 花钱 | none→high | 金币要有去处 | **1.2**（或未拆时的 1.5） |
| 编队 / 站位 | none | 小队核 | **2.0 / 2.1** |
| 放连携 | none | 2.0 承诺第 1 条 | **2.5** |

### 核心循环（1.0 权威形态）

```text
据点整备（看属性、加点、换装、休息）
    → 选出征节点
    → 回合选择（攻 / 技 / 防 / 药）
    → 风险：HP 归零则失败回据点，本场无经验无掉落
    → 反馈：伤害数字、RG 涨落、经验条、金币
    → 奖励：经验、固定装备、通关标记
    → 新约束：等级技能、更强节点、背包与药水缺口
    → 再整备
```

2.0 循环把「整备」扩成编队/站位/羁绊，把「选择」扩成多人行动。那是新核，不是 1.0 的皮肤。

## Design Pillars

| 支柱 | 设计含义 | 砍功能时用这把尺 |
| --- | --- | --- |
| 三条资源都有代价 | HP 存亡、MP 稳定手段、RG 高风险爆发且战终清零 | 不把 RG 做成战外养成条；不加第四条主资源 |
| 养成能在战斗里读出来 | 加点、换装、学技能必须改变下一场的伤害或生存 | 不提前做玩家读不到的词缀、套装、软硬上限 |
| 先单人可读，再小队更强 | 编制只在单人循环值得重复之后出现 | 1.x 禁止队友、站位、连携、ATB |

## 版本梯子总表

三个时代。小版本只加厚当前时代的核；大版本才允许换核。

```text
时代 A  单人烬火     1.0 → 1.1 → 1.2 → 1.5
                      证明：一个人 + 三条资源 + 据点循环

时代 B  小队烬火     2.0 → 2.1 → 2.5
                      证明：第二人改变决策，再谈四人与连携

时代 C  长线烬火     3.0 → 3.x / 上线后
                      证明：有足够内容与职业深度，值得称为可发布 RPG
```

| 版本 | 阶段角色 | 一句话目标 | 规则从哪来 | 代码何时能写 |
| --- | --- | --- | --- | --- |
| **1.0** | MVP / First Playable | 建角→据点→4 战→能赢能输，养成可读 | `docs/v1.0` **原文** | **现在（唯一开工范围）** |
| **1.1** | First Playable 品质 | 同样规则，打完不觉得是调试器 | 本提案新切 | 1.0 门通过之后 |
| **1.2** | 单人循环加厚 | 金币有去处，路线更长，仍 1v1 必中无状态 | 从 `docs/v1.5` 拆出非战斗部分 | 1.1 通过之后 |
| **1.5** | 单人战斗加厚 | 冷却、暴击、坚守/灼烧让回合出现读招 | `docs/v1.5` 战斗半部 | 1.2 通过之后 |
| **2.0** | 小队 Vertical Slice | 旅团长 + 1 名队友，第二人必须改变决策 | 从 `docs/v2.0` 极小切片 | **1.5 门通过之后** |
| **2.1** | 四人编制与站位 | 出战最多 4、前后排、名册 | 2.0 §4.4 | 2.0 切片证明「不是双倍 HP」之后 |
| **2.5** | 小队深度 | 技能装配/技能点、羁绊连携、最小状态集、Boss 机制 | 2.0 §7、§4.6、§9.8–9.10 | 2.1 站位可被读懂之后 |
| **3.0** | 可发布内容体量 | 多章节、四职满配、转职、防具三槽与轻量词缀、手柄完整、三档难度 | 2.0 §16.2 + 内容下限表 | 2.5 承诺可对外说之后 |
| **3.x / 上线后** | Post-launch | 打造重铸、召唤、自动战斗、图鉴 CG、NG+ | 2.0 §16.2 剩余 | 不得作为立项前提 |

若日后推翻 OPT-001，才考虑取消 1.2、让 1.1 之后直接做整包 1.5。当前 **1.2 存在且是 1.5 的前置**。

## 时代 A · 单人烬火

### 1.0 最小可玩（当前开发）

**目标：** 没有它就无法测试玩家承诺。规格不改写，以 `docs/v1.0` 为准。

| 项 | 内容 |
| --- | --- |
| 玩家路径 | 名字 + 卫士/咒术师 → 据点五入口 → 3 小战 + 烬狼 → 经验/金币/固定装备 → 失败回据点保留养成 |
| 必须有 | 1 人、HP/MP/RG、六维加点、三槽固定装备、无冷却技能、1v1 速度先手、4 节点、1 存档槽 |
| 明确没有 | 商店、暴击、状态、队友、教学战、手柄、词缀 |
| 产出 | 可玩包 + V1-01～V1-11 全过 |
| owner | 程序（当前项目默认） |
| 周期假设 | 单人数周量级，`assumption`，用实际耗时校准 1.1 |
| 通过 | 验收表全过；至少 1 人能独立打到 Boss；能口头说出 RG 怎么满、失败为什么没掉落 |
| 失败 | 打不完闭环；胜负/经验/存档与规格不一致；为「顺便」做了商店或状态 |
| 决策 | **Go** → 1.1；**Observe** → 补 UI/存档但不开新系统；**Pivot** → 三条资源读不懂则先改 1.0 规则本文而不是加系统；**Stop** → 连 1v1 回合都无法稳定结算 |

1.0 最危险假设：`ASM-RG-READABLE-001`。验证见 `designos/04-experiments/EXP-LOOP-1.0-001/`。

### 1.1 可玩品质（新小版本）

**目标：** 规则不变，让 1.0 能给人玩，而不是只能给作者点。1.0 自己写了「占位图即可」；1.1 补上阅读与反馈。

| 包含 | 不包含 |
| --- | --- |
| 战斗日志或飘字（伤害、RG、升级） | 新技能、新敌人公式 |
| 战斗 1x / 2x（2.0 §9.11 提前借用表现，不借用 ATB） | 商店、暴击、冷却、状态 |
| 空状态与坏档提示打磨（1.0 §11 已要求，本版当验收而不是「有就行」） | 教学长流程、多语言 |
| 选中/命中/胜负的占位音效 | 高精度立绘、法术全特效 |
| 据点/战斗信息可读：三条条有文字不只靠颜色（2.0 无障碍要求的最小集） | 手柄必做 |

| 项 | 内容 |
| --- | --- |
| 产出 | 同一条 4 战路线的「可试玩」包 |
| 通过 | 未参与开发的人能不靠作者讲解打完第 1–2 战；失败原因能从界面读出；2x 下结算不错乱 |
| 失败 | 仍必须开编辑器才能玩；日志与实际结算不一致 |
| 决策 | **Go** → 1.2；**Pivot** → 信息过载则减日志留飘字，仍不加系统 |

### 1.2 单人循环加厚（从 1.5 拆出）

**目标：** 验证「再出征」是因为循环有缺口（药、金、路线），不是因为战斗公式变复杂。

从 `docs/v1.5` **只取**：

- 据点商店（绷带/清水/铁衣/职业二阶武器）
- 主线 6 节点 + 事件二选一 + 焦骨刷级
- 等级上限 12、1.0 满级档可续升
- 手动存档 3 槽
- 节点按序解锁

**本版不做：** 暴击、LUK 生效、技能冷却、坚守、灼烧、Lv.7 新技能。敌人数值可沿用 1.5 表，但结算仍走 1.0 公式（必中、无暴击、无状态）。

| 项 | 内容 |
| --- | --- |
| 通过 | V15-01～04、V15-09 中与商店/路线/存档相关的项；金币会花出去；事件只奖一次 |
| 失败 | 商店没人买；路线变长但无人刷；或偷偷做了暴击/状态 |
| 决策 | **Go** → 1.5；**Pivot** → 货架或节点结构改表，不改战斗核 |

### 1.5 单人战斗加厚

**目标：** 在仍然是 1 人 1v1 的前提下，让回合出现「这回合不该平砍」。

从 `docs/v1.5` **取剩余**：

- LUK → 暴击（仍必中）
- 贵技能 CD、Lv.7 坚守 / 余烬
- 仅 `guard_stance` 与 `burn` 两种状态
- 战斗 UI：冷却原因、暴击反馈、状态名

仍禁止：队友、ATB、闪避未命中、词缀、转职、猎刃/祈火使。

| 项 | 内容 |
| --- | --- |
| 通过 | V15-05～08、V15-10；玩家能解释为何留怒技 CD、为何上灼烧 |
| 失败 | 暴击把战斗打成掷骰；状态变成图标动物园；或开始做眩晕/护盾 |
| 决策 | **Go** → 才允许讨论 2.0；**Observe** → 调数值不新开系统；**Pivot / Stop** → 单人加厚后仍无人重复出征，不要用队友掩盖 |

时代 A 结束时的玩家承诺验收：养成能读出来、三条资源有代价、单人路线值得刷。尚未验收「小队比个人更强」。

## 时代 B · 小队烬火

直到 1.5 **Go**，本节全部 Parked。

### 2.0 小队 Vertical Slice

**要证明的假设：** `ASM-PARTY-CHANGES-DECISIONS-001`（第二人改变决策）。

建议切片（derived，需 Human Gate）：

| 包含 | 排除（尽管 2.0 原文有） |
| --- | --- |
| 旅团长 + **1** 名可招募队友 | 一上来 4 人出战 |
| 职业数据扩展到 4 职；切片里出现与旅团长不同的第二职 | 技能树深分支、转职 |
| 仍 **速度高的先手**、攻击仍 **必中** | ATB 速度条、命中/闪避、弱点/击破 |
| 装备仍是武器/防具/饰品各 1，固定数值 | 防具三槽、词缀、套装、强化 |
| 1 据点 + 很短路线（够打出双人差异即可） | 12+ 节点、多难度 |
| 失败：全灭才失败；旅团长倒下战斗可继续（D7 倾向） | 立即重试以外的惩罚实验可后做 |
| 未出战经验若只有 2 人可暂不实现 | 羁绊、连携、战场技 |

| 项 | 内容 |
| --- | --- |
| 体验路径 | 建角 → 招募 1 人 → 2v2 或 2v1 → 看见职业互补（例如卫士承伤、咒术师输出）→ 回据点换谁出战 |
| 通过 | 同一玩家能说出「这回合该谁行动/该打谁」；关掉队友会明显变难或变蠢，而不是只变慢 |
| 失败 | 队友是第二个自动攻击按钮；UI 两套条读不过来 |
| 决策 | **Go** → 2.1；**Pivot** → 减 UI 或改 AI，仍不加词缀/ATB；**Stop** → 小队核不成立则停留在 1.5 单人游戏，不要用内容堆过 |

2.0 原文 §2.4 的「名册 5 出战 4、8 场遭遇、完整词缀战斗」是 **3.0 内容预算**，不是本切片。

### 2.1 四人编制与站位

| 包含 | 排除 |
| --- | --- |
| 出战 1–4、必须含旅团长；2 前 2 后；站位伤害/命中修正 | 羁绊连携 |
| 名册上限可先 5，不必一次 8 | 重整阵型的完整战场技可后置，但前排全倒后排被拉前要做 |
| 教学里「脆皮换后排」这一段 | 教学 6 步长流程一次做完 |

| 通过 | 玩家能说出前后排为什么换人；空位 3 人队可打 |
| --- | --- |
| 失败 | 站位变成看不见的隐藏乘区；4 人 UI 崩坏 |

### 2.5 小队深度

此时才引入 2.0 里真正贵、真正改变对局的系统，且 **一次仍不要全上**：

**本版建议必做：**

- 主动栏 4 格 + 技能点浅树（每职先凑齐可用的子集，不必一次满配）
- 羁绊 0–3 与至少 2 对连携（条件只留羁绊 + 资源，站位仅加成）
- 状态最小集：眩晕、一种 DOT、护盾、沉默（对应 2.0 A13，但收紧数量）
- 1 个有阶段的路线 Boss：必须用到 HP/MP/RG 中至少两种机制

**本版建议仍 Park：**

- ATB（换掉已验证的速度先手，风险等于再做一款战斗）
- 弱点/击破
- 装备词缀与强化
- 转职

| 通过 | 能对外复述 2.0 三条体验承诺；连携不是菜单化石；Boss 不是纯堆 HP |
| --- | --- |
| 失败 | 技能栏与状态图标导致 1.0 的可读性回退 |
| 决策 | **Go** → 3.0 内容生产；**Pivot** → 砍连携或砍状态，保留编制 |

## 时代 C · 长线烬火

### 3.0 可发布内容体量

对应原 2.0「第二期」里 **内容与职业深度** 那一半，加上原「第一期」里被推迟的量产项。

| 包含 | 仍推迟到 3.x |
| --- | --- |
| 多章节线性节点图（不是开放世界） | 打造、重铸、镶孔、耐久 |
| 四职技能/装备线补满；转职（D1 原定第二期） | 战场召唤物、大型场地机关 |
| 防具头/躯/足、饰品两槽；词缀池收紧；强化 +1~+3 且 100% 成功 | 自动战斗、战斗回放 |
| 故事 / 标准 / 严苛三档 | 成就、图鉴、CG 长片 |
| 手柄完整可玩（D8 从预留升格） | NG+ / roguelike 周目 |
| 教学可跳过的完整短流程 | 更多职业（刺客、召唤等） |

### Go / Observe / Pivot / Stop（全局）

**Go：** 本版通过标准命中，且没有把下一时代的系统偷做进来。

**Observe：** 体验暧昧但归因清楚（例如「药太少」而不是「不知道在玩什么」）→ 只改表与文案，延长观察，不跳版本。

**Pivot：** 核被证伪 → 改当前时代的规则本文（回写 `docs/v*`），不允许用下一时代功能当补丁。

**Stop：** 1.0 结算都不稳；或 1.5 后无人重复出征且改规则无效；或 2.0 切片证明小队无意义还坚持堆 4 人词缀。

不要用「后续调优」「先做着」当作过门。
